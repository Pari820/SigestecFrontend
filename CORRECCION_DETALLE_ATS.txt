SIGESTEC – Corrección de visualización de etapas del ATS

Se modificaron únicamente:
- src/app/features/ats/pages/ats/ats.ts
- src/app/features/ats/pages/ats/ats.html
- src/styles.css (estilos de tabla)

El JSON de etapas se interpreta en Angular y se muestra como tabla.
No es necesario alterar tablas, registros, endpoints ni backend.

Para iniciar:
1. Abre esta carpeta sigestec-frontend en VS Code.
2. Ejecuta npm install (si aún no se instalaron dependencias).
3. Ejecuta npm start.
4. Abre el detalle de un ATS ya registrado y verifica la tabla.

Esta versión parte del último frontend con integración Google/Gmail.
Si utilizas otra versión, sustituye los archivos indicados, preservando el resto de tu proyecto.
